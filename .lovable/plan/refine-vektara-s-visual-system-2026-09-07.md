# Refine Vektara’s Visual System

## Goal
Make the home and contact pages feel more premium and persuasive, using the references for inspiration while preserving Vektara’s original machined-metal identity.

## Changes
- Enrich the metallic palette with brighter chrome surfaces, charcoal contrast bands, and a restrained electric-blue accent.
- Rework the opening area into a stronger first impression with clearer hierarchy, layered depth, animated technical visuals, and more confident calls to action.
- Improve section rhythm and card presentation across capabilities, process, proof, and engagement so the page feels less flat and more polished.
- Add purposeful motion: subtle parallax-like movement, progressive reveals, light sweeps, animated counters/indicators, and richer hover feedback, all respecting reduced-motion settings.
- Bring the contact page and shared header into the same upgraded visual language without changing the form workflow or navigation structure.
- Verify home, contact, section links, desktop layout, mobile layout, and browser errors.

## Technical Notes
- Keep the existing TanStack routes and shared navigation.
- Extend semantic design tokens and reusable animation utilities in the global stylesheet.
- Use lightweight CSS and React interactions only; no copied Creative Tim assets or template code.
- Preserve current content and contact behavior unless small wording adjustments are needed for visual fit.
